Plain PowerPoint

Simplify slides to deterministic, plain-text-only slides — great for accessibility, printing, and consistency.

Open README.md

Quick Start Guide

  1. Download the repo: 
    git clone https://github.com/keeganosler/plain-powerpoint.git
  2. Install dependancies: 
    npm install
  3. Run dev server: 
    npm run dev-server
  4. Sideload into PowerPoint:
    1. Open a PowerPoint presentation
    2. Home -> Add-ins -> More Add-ins -> My Add-ins -> Upload My Add-in
    3. Browse -> Select /your/path/to/plain-powerpoint/manifest.xml
    4. Click upload and get started with Plain PowerPoint!

More Info

Features

  • Simplifies slides to plain text objects (removes fills, images, and non-text shapes).
  • Heuristic background detection with a white-background fallback to ensure consistent output.
  • Deterministic behavior — same input → same simplified slide output.
  • Works on Desktop and Web (subject to host capability limitations).

Limitations

  • May not preserve text formatting exactly (fonts, sizes, and styles are simplified).
  • Animation, transitions and embedded media are not preserved.
  • Host capability differences may affect background detection or image exports; placeholder logic is used when exact values aren't available.
